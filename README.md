# Змейка на Pygame

Змейка проходит сквозь границы поля, растёт после съеденного яблока 
и начинает игру заново при столкновении с собой.

## Установка

1. Создайте виртуальное окружение:

   ```bash
   python3 -m venv env
   ```

2. Активируйте его.

   ```bash
   source env/bin/activate
   ```

3. Установите зависимости:

   ```bash
   python3 -m pip install -r requirements.txt
   ```

## Запуск

Из корня проекта выполните:

```bash
python3 the_snake.py
```

Управление выполняется клавишами со стрелками. Закрытие окна завершает игру.
